# Фаза 4: Дальнейшее развитие проекта

## Изменения фазы 4

### Новые методы кластеризации

Добавлено 7 новых методов кластеризации в директорию `ClusteringMethods/`:

1. **WaveClustering** (`WaveClusteringAlgorithm.py`)
   - Кластеризация на основе вейвлет-преобразования
   - Поддержка многомасштабного анализа данных
   - Параметры: размер сетки, тип вейвлета, количество уровней разложения, порог плотности
   - Зависимости: PyWavelets, scipy

2. **BallTree Hierarchical Clustering** (`BallTreeClustering.py`)
   - Иерархическая кластеризация с использованием BallTree структуры данных
   - Поддержка различных метрик расстояния (евклидова, манхэттенская, Чебышёва)
   - Методы linkage: ward, complete, average, single
   - Зависимости: scikit-learn, scipy

3. **HPStream Clustering** (`HPStreamClasteringAlgorithm.py`)
   - Проекционная кластеризация для высокомерных потоковых данных
   - Автоматический выбор значимых размерностей
   - Поддержка инкрементального обучения через скользящее окно
   - Зависимости: scikit-learn

4. **VP-Tree Bregman Divergence Clustering** (`VPTreeClustering.py`)
   - Кластеризация на основе VP-tree с поддержкой различных дивергенций
   - Поддержка дивергенций: евклидова, Хеллингера, Бхаттачарьи
   - Метрики: манхэттенская, Чебышёва, косинусная
   - Реализация без зависимости от pyBregman (использует только scipy)
   - Зависимости: scikit-learn, scipy

5. **KMeans с опциональной PCA** (`KMeansClustering.py`)
   - Реализация KMeans из scikit-learn с возможностью предварительной PCA декомпозиции
   - Поддержка различных методов инициализации (k-means++, random)
   - Настраиваемое количество инициализаций и итераций
   - Зависимости: scikit-learn

6. **MiniBatchKMeans** (`MiniBatchKMeansClustering.py`)
   - Оптимизированная версия KMeans для больших наборов данных
   - Обработка данных батчами для снижения потребления памяти
   - Поддержка опциональной PCA декомпозиции
   - Зависимости: scikit-learn

7. **AgglomerativeClustering** (`AgglomerativeClustering.py`)
   - Иерархическая агломеративная кластеризация из scikit-learn
   - Методы linkage: ward, complete, average, single
   - Поддержка метрик расстояния и порога `distance_threshold`
   - Зависимости: scikit-learn

### Новые методы кластеризации (сентябрь 2026)

В сентябре 2026 добавлено ещё 7 методов кластеризации в директорию `ClusteringMethods/`.
Для каждого метода созданы тестовый скрипт в `TestMethods/`, результаты тестов
в `TestMethods/Images/` и описание в `ClusteringMethods/README.md` (методы 20-26).

1. **MeanShift** (`MeanShiftClustering.py`)
   - Кластеризация методом сдвига среднего из scikit-learn
   - Число кластеров определяется автоматически по радиусу окна `bandwidth`
   - Автоматический подбор радиуса по параметру `quantile`
   - Для изображений обучение на выборке пикселей с последующим отнесением к ближайшему центру
   - Зависимости: scikit-learn
   - Автор: Собиров Тельман

2. **K-Medians** (`KMediansClustering.py`)
   - Вариант KMeans, в котором центр кластера — медиана по каждой координате
   - Устойчивость к выбросам, манхэттенская метрика по умолчанию
   - Инициализация k-means++ или random
   - Зависимости: pyclustering, scikit-learn
   - Автор: Собиров Тельман

3. **X-Means** (`XMeansClustering.py`)
   - Расширение KMeans с автоматическим подбором числа кластеров от `kmin` до `kmax`
   - Критерии разделения кластеров: BIC, MNDL
   - Зависимости: pyclustering, scikit-learn
   - Автор: Курбанов Рамазан

4. **MBSAS** (`MBSASClustering.py`)
   - Модифицированный базовый последовательный алгоритм
   - Число кластеров определяется порогом расстояния `threshold` (не больше `maximum_clusters`)
   - Опциональное перемешивание точек (результат зависит от порядка обработки)
   - Зависимости: pyclustering, scikit-learn
   - Автор: Курбанов Рамазан

5. **SOM (Self-Organizing Map)** (`SOMClustering.py`)
   - Самоорганизующаяся карта Кохонена: один нейрон сетки `rows x cols` — один кластер
   - Типы соединения нейронов: grid_eight, grid_four, honeycomb, func_neighbor
   - Для изображений обучение на выборке пикселей
   - Зависимости: pyclustering, scikit-learn
   - Автор: Курбанов Рамазан

6. **CLIQUE** (`CliqueClustering.py`)
   - Кластеризация на основе сетки и плотности
   - Плотные смежные ячейки сетки объединяются в кластеры, точки в разреженных ячейках — шум (-1)
   - Зависимости: pyclustering
   - Автор: Кузнецов Сергей

7. **CLARANS** (`ClaransClustering.py`)
   - Кластеризация на основе K-Medoids со случайным поиском
   - Центры кластеров — реальные точки данных (медоиды)
   - Зависимости: pyclustering
   - Автор: Кузнецов Сергей

В K-Medians и X-Means обойдена несовместимость pyclustering с numpy >= 2.
В K-Medians, X-Means, MBSAS и SOM добавлен автоматический переход на
Python-реализацию, если C++ часть pyclustering (ccore) недоступна на платформе
(например, macOS на процессорах Apple).

### Новые методы кластеризации (октябрь 2026)

В октябре 2026 добавлено ещё 2 метода кластеризации в директорию `ClusteringMethods/`.
Для каждого метода созданы тестовый скрипт в `TestMethods/`, результаты тестов
в `TestMethods/Images/` и описание в `ClusteringMethods/README.MD` (методы 27-28).

1. **DENCLUE** (`DENCLUEClustering.py`)
   - Кластеризация на основе гауссовской плотности
   - Поиск и объединение аттракторов плотности, выделение шума (-1)
   - Блоковая обработка расстояний и учёт повторяющихся точек
   - Зависимости: numpy, scipy, scikit-learn
   - Автор: Пантелеев Артём

2. **FCM (Fuzzy C-Means)** (`FCMClustering.py`)
   - Нечёткая кластеризация из pyclustering
   - Инициализация kmeans++ или random, фиксированный random_state
   - Нормализация данных и автоматический переход с CCORE на Python
   - Зависимости: pyclustering, scikit-learn, numpy
   - Автор: Пантелеев Артём
